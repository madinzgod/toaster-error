A tiny program that writes one line — the funniest error message a kitchen toaster would show its owner — to `/output/entry.txt`. Deadpan, specific, and well under the 120-character cap: a real component failure, reported in a real error-message voice, with the blame placed exactly where it belongs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
